# StayHub frontend

React UI plus the Convex backend (`convex/`).

See the root [README](../README.md) for full setup and demo accounts.

```bash
npm install
npx convex dev
npm run seed
npm run dev
```

`VITE_CONVEX_URL` in `.env` should point at your Convex deployment
(`https://exuberant-rook-204.convex.cloud`).
